# GPA Calculator

A browser-based semester GPA calculator with live results and grading scales for four universities.

## Run

Open `index.html` in a modern browser. No installation or build step is required.

## Use

1. Select your university's grading scale.
2. Add courses, choose each course type, and select its grade.
3. Read the live GPA, enrolled credits, and quality points in the results panel.

Major courses count for 3 credits, minor courses for 2, and practicals for 1. The GPA stays blank until every course has a grade. Changing universities refreshes grade options and clears any grade that is not available on the selected scale.
